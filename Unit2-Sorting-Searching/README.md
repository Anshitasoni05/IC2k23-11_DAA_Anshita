# Unit2 Sorting Searching

Bubble, selection, insertion, merge, quick, heap and radix sorting; binary search; student record and hash dictionary examples.

## How to compile and run
From the repository root, for each program:
```bash
javac -d out Unit2-Sorting-Searching/ProgramName/Main.java
java -cp out Main
```
Replace `ProgramName` with the required program folder. Compile one program at a time because each is a standalone exercise with a `Main` class.

## Documentation checklist
For every exercise, record:
- **Algorithm:** identify the data structure and key operations.
- **Pseudocode:** write the steps before implementation.
- **Dry run:** trace a small input manually.
- **Complexity:** include best, average and worst cases where applicable.
- **Real-life use:** connect the structure/algorithm to an application.
- **Screenshots:** add genuine console screenshots under a `screenshots/` subfolder.

## Learning outcomes
Bubble, selection, insertion, merge, quick, heap and radix sorting; binary search; student record and hash dictionary examples. Understand operation preconditions, edge cases, and the time/space trade-offs involved.
