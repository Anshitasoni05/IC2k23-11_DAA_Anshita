# Reflection — Unit5 Queues

## What I learned
Circular array queue, deque, priority queue, and a round-robin process scheduling simulation.

## Difficulties
Boundary conditions such as empty structures, invalid indices, duplicate values, and incompatible dimensions require explicit handling.

## Optimizations
Choose a representation based on the operations required. Prefer iterative traversal where recursion depth may become large, and benchmark algorithms on multiple input patterns rather than relying only on asymptotic complexity.

## Further work
Add JUnit tests, richer input validation, and measured benchmark tables for the programs in this unit.
